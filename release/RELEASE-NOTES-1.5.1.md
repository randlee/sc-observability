# Release Notes — v1.5.1

## `sc-otel` distribution

- `sc-otel-cli` is published as the `sc-otel` command-line package.
- Install with `cargo install sc-otel-cli`, a matching GitHub release archive,
  Homebrew (`randlee/homebrew-tap`), Scoop (`randlee/scoop-bucket`), or Winget
  (`randlee.sc-otel`).
- Archives cover macOS Apple silicon and Intel, Linux x86_64 and arm64, and
  Windows x86_64. Each archive and the Homebrew formula include the offline
  manual at `share/doc/sc-otel`; the Cargo package embeds the same manual.

Publication, tagging, and external release execution remain separately
authorized.
